# memory-game
На поле 16 карточек. 8 пар картинок. Нужно открывать по две карточки и найти все пары за как можно меньше ходов.

Игра начинается сама при открытии страницы. Если картинки совпали, карточки остаются открытыми. Если нет, они закрываются через секунду. Когда найдены все пары, появляется окно победы с числом ходов.
Вверху есть кнопки «Новая игра» и «Таблица лидеров». «Новая игра» перемешивает карточки и обнуляет счётчики. «Таблица лидеров» показывает до 10 лучших результатов. 

## Как запустить
1. Склонируйте репозиторий и откройте папку проекта.
2. Откройте файл `index.html` в браузере.
